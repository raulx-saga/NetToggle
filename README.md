# NetToggle
an application to automate swtiching networks (5g -> 4g, 4g-> 5g) in a single click
Build specifically for samsung devices, my model (galaxy a14 5g ) 

why make it what's the purpose ? 
-> in my area my mobiles 5G network only works when the phone is kept in a window, while when I'm browsing web on my bed, the 4G network works more efficiently, the problem is switching network modes is kind of a annoying process so, to automate this process I have build this solution

it automates everything meaning it does not work truly in background but rather using accessebility clicks, since making it truly background only would require me to root my phone, which would be overkill for this simple requirement. 

feel free to report any bugs, or make changes yourself. 
this is a vibe coded repository since I don't do a lot of android dev.
